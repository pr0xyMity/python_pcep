# Python PCEP Learning with Jupyter Notebooks

A comprehensive Python learning repository designed for the **PCEP (Python Certified Entry-Level Programmer)** certification. This repository includes interactive Jupyter notebooks and practical Python examples to help you master Python fundamentals.

## 📚 What's Inside

### Interactive Jupyter Notebooks
- **Module 1**: Introduction to Python and Computer Programming
- **Module 2**: Data Types, Variables, Basic I/O, and Operators
- **Module 3**: Boolean Values, Conditional Execution, Loops, and Lists
- **Module 4**: Functions, Tuples, Dictionaries, and Exceptions

### Python Examples
- **Calculator**: Basic arithmetic operations with functions
- **Grade Manager**: Student grade tracking with lists and dictionaries
- **Guessing Game**: Number guessing game with loops and conditionals

## 🚀 Getting Started

### Prerequisites
- Python 3.8 or higher
- pip (Python package installer)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/pr0xyMity/python_pcep.git
   cd python_pcep
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch Jupyter Notebook**:
   ```bash
   jupyter notebook
   ```
   
   This will open Jupyter in your browser. Navigate to the `notebooks/` directory to start learning!

## 📖 How to Use This Repository

### For Learning with Jupyter Notebooks

1. Start with **Module 1** and work through each notebook sequentially
2. Each notebook contains:
   - Concept explanations
   - Code examples you can run
   - Practice exercises to test your knowledge
3. Run code cells by pressing `Shift + Enter` or clicking the "Run" button
4. Modify the code and experiment to deepen your understanding
5. Complete the practice exercises at the end of each notebook

### For Practicing with Python Scripts

Run the example scripts from the command line:

```bash
# Calculator
python examples/calculator.py

# Grade Manager
python examples/grade_manager.py

# Guessing Game
python examples/guessing_game.py
```

## 🎯 Learning Path

1. **Week 1**: Complete Modules 1-2, understand basics and data types
2. **Week 2**: Complete Module 3, practice loops and lists

4. **Week 4**: Review all modules, complete all exercises, run example scripts

## 💡 Tips for Success

- **Practice regularly**: Code daily, even if just for 30 minutes
- **Experiment**: Modify the examples and see what happens
- **Debug actively**: When you encounter errors, read them carefully and learn from them
- **Use the exercises**: Complete all practice exercises to reinforce learning
- **Build projects**: After completing modules, try building your own small programs
